# euforia-assets

Public image assets for EUFORIA email campaigns. Gmail blocks images embedded inside an email, so each image lives here and is referenced by its raw URL.

## Usage

Reference an image as:

```
https://raw.githubusercontent.com/khalilmaaouni/euforia-assets/main/vouchers/<file>
```

## Contents

- `vouchers/euforia-gift-voucher-sep05-2026.png`: 1,500 yen off gift voucher, friends' guest list, BORN AGAIN at ZEROTOKYO, 5 September 2026.

## Rules

No CI, no workflows. Images only, no personal data.
