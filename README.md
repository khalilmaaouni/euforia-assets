# euforia-assets

Public image assets for EUFORIA email campaigns. Gmail blocks images embedded inside an email, so each image lives here and is referenced by its raw URL.

## Usage

Reference an image as:

```
https://raw.githubusercontent.com/khalilmaaouni/euforia-assets/main/<folder>/<file>
```

## Contents

- `vouchers/euforia-gift-voucher-sep05-2026.png`: 1,500 yen off gift voucher, friends' guest list, BORN AGAIN at ZEROTOKYO, 5 September 2026.
- `heroes/euforia-tower-of-terror-oct24-2026-hero.jpg`: 1120x630 email hero, TOWER OF TERROR flyer (EUFORIA x BUNKER, Halloween, Shibakoen, 24 October 2026).
- `banners/euforia-cocabombs-oct24-2026-banner.jpg`: 1120x630 email banner, free CocaBombs and drinking games at the bar, with official Cocalero product photos (partner), TOWER OF TERROR email, 24 October 2026.
